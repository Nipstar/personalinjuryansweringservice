# Feeder site build brief (Next.js)

This repo is one Call Della feeder site, built from the calldella.com codebase (Next.js 16, static export, Tailwind 4, React 19). It shares calldella.com's look, components and SEO/GEO foundations.

## Source of truth
1. `docs/FEEDER_PLAN.md`: page list, keywords, titles, H1s, SPIN structure, linking. `docs/FEEDER_COPY.md`: full copy for A1, B1, B2 (flattened .docx: tables are one cell per line). `docs/BUILD_FEEDER_SITES.md`: rules, components, schema, budgets and QA. It was written for Astro: ignore the Astro specifics, keep the rules.
2. `docs/DELLA_BRAND.md` (voice, visuals), `docs/calldella-llms.txt` (fixed description).
3. calldella.com source, read-only, for patterns and facts: `~/dev/call-della-site` (e.g. `src/app/compare/*` for comparison pages, `src/app/operations/*` for calculators, `src/app/intake-playbook/_ui.tsx` for Prose/Table helpers).

## Overrides (decided 25 Oct 2026; these win over the docs)
- **CTA:** the only conversion is **Book a demo** (30 minutes, a live Della call for their practice area). It opens the GHL booking widget in a modal: iframe `https://crm.antekautomation.com/widget/booking/4rCy7x8UfYzn4YktNNkF` (allow="payment", scrolling="no") plus `https://crm.antekautomation.com/js/form_embed.js` for auto-height. Load iframe and script **on first click only**, never at page load (copy the pattern from `~/dev/call-della-site/src/components/BookingModal.tsx` as vanilla JS). Secondary CTA: "See the dossier" (anchor to the sample brief). No "Hire Della" until `ctaMode: 'start'` (keep the config value; default `'book'`).
- **No phone numbers anywhere.** No tel: links, no demo lines, no tracked numbers, no call_click. The sample dossier must not show a phone number. A build test fails on any `tel:` or US phone pattern in dist.
- **Brand in titles:** use "| Call Della", not "| Della".
- **Dropped pages:** B9 (/immigration/) and B10 (/criminal-defense/) are not built; site B links to `https://calldella.com/immigration` and `https://calldella.com/criminal-defense` instead. B5 primary stays "ai receptionist for law firms" but drop the secondaries "legal intake automation", "automated legal intake" and "ai legal intake" (calldella.com owns those).
- **Plans** (shared config only, never typed in a page): Solo $329/month, 300 minutes, for solo lawyers; Practice $598/month, 600 minutes, small and growing firms; Group custom (more than one practice area, CRM webhook, custom minutes). Overage $0.50/min. Month-to-month, no setup fee. Includes (every plan): Della answering in the firm's name nights, weekends and holidays; the Call Della dashboard (every call as a dossier with summary, urgency score, recording and transcript); urgent-call **email** alerts to the attorney on call; morning brief by 7am; state recording disclosure; own Della number with forwarding and a test call before go-live. `[confirm]` items in the copy (Slack, custom intake on Practice) are NOT included: drop them.
- **Feature flags** (all false unless noted): smsAlerts, slackAlerts, crmIntegrations (Clio/Filevine/etc), spanishPI, spanishCriminal, soc2, massTortFlow. spanishImmigration = true. Copy may only claim a feature whose flag is true.
- **A6 intake form email capture:** config `leadWebhookUrl` defaults to empty. When empty, the form is replaced by "Email hello@calldella.com and we'll send the editable template." When set, the form posts JSON {email, firm, page, turnstileToken} to it, with a Cloudflare Turnstile widget (site key `0x4AAAAAAFljNkiI7CbG-mOH`, valid on both feeder domains) and a visible privacy note.
- **Schema ids:** reference calldella.com's entities, don't redefine them: Organization `https://calldella.com/#org`, founder Person `https://calldella.com/about/andy-norman#person`, offers `https://calldella.com/pricing#solo` / `#practice` / `#group`. Each feeder page still emits a minimal Organization node with that @id (name Call Della, url calldella.com, description = the fixed description, parentOrganization Antek Automation antekautomation.com) so the page is self-describing.
- **Statistics:** only from pages fetched and read in this session. Known working sources: Oklahoma Bar Journal (Sept 2025) https://www.okbar.org/answering-the-call-why-responsiveness-is-critical-for-law-firm-success/ (Clio 2024 secret shopper: 40% answered, down from 56% in 2019; 48% unreachable); Lawyers Mutual NC (2019) https://www.lawyersmutualnc.com/blog/how-your-telephone-is-costing-you-clients (ABA LPD study: under 10% reached a lawyer, 32% voicemail, 42% waited 3+ days). The ABA Law Practice Magazine page returns 403 to bots. Re-fetch before use.
- **calldella.com links:** only these exist: / /how-it-works /pricing /security /about /about/andy-norman /contact /personal-injury /criminal-defense /immigration /compliance (+ /aba-formal-opinion-512-explained /attorney-client-privilege-ai-intake /hipaa-at-intake-phi /call-recording-consent-by-state) /intake-playbook (+ /what-should-be-on-a-pi-intake-form /how-to-write-pi-intake-script /intake-red-flags-declining-cases /law-firm-client-intake-process /law-firm-client-intake-form) /operations (+ /missed-call-cost-calculator /cost-per-signed-case-calculator /after-hours-intake-comparison /law-firm-missed-calls-data) /states /case-types /compare (+ /smith-ai /answering-legal /posh /ruby) /glossary. Every link to calldella.com carries `utm_source=<feeder domain>&utm_medium=feeder&utm_campaign=<page-slug>&utm_content=<position>` (build it with a helper, never by hand).
- **Copy rules** (from the build doc, restated): US English. No em dashes, no exclamation marks. Banned: leverage, seamless, robust, cutting-edge, revolutionary, solutions, game-changer, unlock, AI-powered, next-generation. Della is "she", an intake specialist, never a receptionist (the domain is the search term; the copy reframes it). Della never gives legal advice and says she is an AI if asked. No testimonials, ratings, review schema, invented call stories presented as real (label examples "Example call" / "Sample").

## What's already in this repo (use it, don't rebuild it)
- `src/lib/site.ts`: the only per-site settings (id, name, domain, tagline, nav, guides dropdown, footer columns). Header and footer read it.
- `src/lib/config.ts`: `SITE_URL` (this site), `CALLDELLA_URL`, booking URL (GHL), Turnstile key, contact webhook.
- `src/lib/plans.ts`: plans, INCLUDES, GROUP_EXTRAS, OVERAGE_PER_MINUTE, DEMO_MINUTES, FLAGS, CATEGORY_DEFINITION. Never type a price.
- `src/lib/utm.ts`: `calldella(path, campaign, content)` builds every calldella.com link with the four UTM params. Never hand-write a calldella.com URL.
- `src/lib/schema.ts`: `graph`, `articleNode`, `serviceNode`, `faqNode`, `offerNodes`, `breadcrumbNode`, `collectionNode`; ids point at calldella.com's Organization, founder and offers. Render with `<JsonLd data={graph(...)} />`. The root layout already emits Organization, WebSite and founder Person.
- `src/data/pages.ts`: the manifest. Every page needs an entry (title 60ish chars + " | Call Della", description 140-160 chars, primary, secondaries, section, summary, dates). Use `export const metadata = pageMeta('/path')`. Sitemap and llms.txt read it; llms-full.txt is generated postbuild.
- Components: `FAQ` (visible <details> + matching FAQPage schema), `ArticleLayout` (H1, answer block, byline, dates, Article schema, citations), `Breadcrumbs` (+ schema), `CTAButton` (opens the booking modal; one shared `BookingModal` in the root layout, GHL widget loaded on first click), `DossierMockup` (SAMPLE dossier), `Pricing` (plan cards from plans.ts), `ContactForm` (Turnstile + webhook), `compare/CompareTable`, `PainScenario`, `Typography`, `Stamp`, `Rule`, `PaperTexture`. `src/data/competitors.ts` has competitor facts fetched 25 Oct 2026 with URLs.
- Speed setup already done: inlined CSS, fonts with `display: optional`, mono font not preloaded. Don't add client components unless needed; keep pages server components.
- `public/`: logo.png, og-default.png (calldella art; make a site-specific og-default.png 1200x630 in the same paper/ink style if you can, e.g. render HTML with Playwright's Chromium).

## Rules
- Every page: one H1 with the primary keyword, an answer block (40-60 words, one concrete sourced fact in the first 60 words), question H2s with self-contained 134-167 word passages, real tables, 5-8 FAQs (40-80 words) via `FAQ`, a sourced statistic, Book a demo CTA, internal links per the plan, visible Published/Updated dates on guides.
- `npm run build` must pass. Then check `out/`: no `tel:`, no US phone pattern, no em dash, no exclamation mark, no banned words, no `TODO(`; every calldella.com link has utm_source, utm_medium, utm_campaign, utm_content; FAQ schema text equals visible text; all meta descriptions 140-160 chars. Write these checks as `scripts/check.mjs` and add `"test": "node scripts/check.mjs"`.
- Lighthouse mobile on the home page and two others (Playwright's Chromium: `python3 -c "from playwright.sync_api import sync_playwright as p\nwith p() as x: print(x.chromium.executable_path)"`, serve `out/` with `npx serve`). Local CPU numbers are noisy; report them but don't chase TBT.
